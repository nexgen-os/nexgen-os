# `packs/` — one folder per country

A country is data: the identifier schemes it uses (building registers,
cadastre, metering points), the vocabulary rows it needs, and the rules its
modules apply — energy sharing, solar obligations, wind perimeters, protected
zones, grid tariffs. Each pack ships with tests that prove its rules on
sample cases, and states who reviewed it.

No pack exists yet. The core names no country.
